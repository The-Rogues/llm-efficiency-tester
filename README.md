# LLM Efficiency Tester Project

## Description:
A project that I made to test different LLMs in Godot for their efficiency and interpretative ability.

## How to Run:
- Clone the repo.
- Open the Godot editor.
- Select Import in the editor's main menu.
- Navigate to the cloned repo on your device and select it.
- Open the imported project in Godot.
- Download the NobodyWho plugin into the project.
- Add an LLM in GGUF format to the project.
- In the main game scene's EfficiencyTester child, name the output files as desired and set the GGUF file's path in the inspector.
- Press the play button in the top right corner of the editor and wait until termination message is printed in the console.
- Navigate to the %APPDATA%\Godot\app_userdata\llm-efficiency-tester\ folder in your file system to retrieve result files.
